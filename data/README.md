# تنظيم البيانات

- `raw/`: ملفات المصدر الأصلية، محفوظة كما وردت. يوجد ملف المهمة المرجعي داخل `raw/reference/`.
- `processed/`: جداول التحليل وقائمة الإجراءات الناتجة عن الأكواد في `src/product_radar/`.
- `SHA256SUMS.txt`: بصمات SHA-256 لملفات المصدر والمراجع؛ استخدمه للتحقق من سلامة الملفات بعد النقل أو النسخ.

لإعادة بناء الملفات المعالجة، نفّذ الأوامر بالترتيب من جذر المشروع كما هو موضح في [README](../README.md). لا تعدّل ملفات `raw/` يدويًا؛ صحّح منطق المعالجة أو أضف إصدار مصدر جديدًا عند الحاجة.
